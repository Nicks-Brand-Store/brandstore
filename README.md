# Brand Store

A React web app implementing various web development tasks.

## Setup

1. Install Node.js from https://nodejs.org/ (LTS version)

2. Install dependencies:
   ```
   npm install
   ```

3. Run the development server:
   ```
   npm run dev
   ```

4. Open the app in your browser at the provided URL (usually http://localhost:5173)
